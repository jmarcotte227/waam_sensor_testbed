# WAAM Sensor Testbed
This repository contains the associated libraries and code to run the smaller WAAM Sensor Testbed at Rensselaer Polytechnic Institute. It requires the use of the UCCNC API which is included in this repo.

Before running the stage, the driver for the UC100 must be installed from here: https://cncdrive.com/MC/UC100%20files%20for%20manual%20installation/UC100_USB%20drivers.zip
